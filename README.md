An interactive Python GUI card game that lets users bet on whether the next card drawn will be a black card (clubs or spades). Special cards are in the deck that when drawn cause all red cards (diamonds or hearts) to be reshuffled into the deck, making it harder to guess if a black card will be drawn next, with that the reward of a successful bet increases. 

Features

- GUI interface with cards displayed on screen
- Betting mechanism
- Saving mechanism
- Bet reward mechanic
- Home screen with rules
- Game over screen

Installation

1. Clone this repository

2. Navigate to project folder

3. Run application
